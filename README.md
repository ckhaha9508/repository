# Nest Launcher

**简体中文** | [English](README.en.md)

<img src="Resources/NestLauncher.iconset/icon_128x128@2x.png" alt="Nest Launcher 图标" width="96" />


Nest Launcher 是一款原生 macOS 应用分组与快速启动工具（类似 Windows 下的 DawnLauncher）。你可以按工作、开发、设计、娱乐等场景整理应用，通过主界面、全局快捷键、菜单栏或桌面悬浮球快速访问。

项目完整公开应用源码、图标资源、构建脚本与测试代码，支持自行审查和本地构建。无需账号，应用数据保存在本机，不依赖在线服务。

第一次做开源 app，希望大家多多包涵，也请各位大佬指教。首个版本利用国庆时间上线，可能会有点粗糙，使用 AI 工具编程（Swift 不太熟），但是经过完整的人工监督。希望大家可以反馈使用意见，我会及时更新。

## 主要功能

### 应用分组与管理

- 自定义分类，支持多级子分类。
- 从 Finder、程序坞或右侧应用库拖入 App，快速加入分类。
- 自动扫描系统、用户应用目录及普通子文件夹，不进入 App 包内部。
- 应用库独立刷新，不会把所有应用自动加入你的分类。
- 支持编辑名称、关键词、备注和收藏标记。
- 列表模式支持多选，批量启动、收藏、移动和移除启动项。

移除启动项只会删除 Nest Launcher 中的记录，不会卸载或删除电脑上的应用。

### 快速查找与启动

- 双击应用，或通过右键菜单启动。
- 按名称、路径、关键词和备注搜索启动项。
- 按名称、启动次数或最近启动时间排序。
- 记录成功打开应用的次数和时间；打开失败时显示提示。
- 默认使用 `Option + Space` 显示／隐藏主界面，可在设置中更换组合。

### 菜单栏与桌面悬浮球

- 关闭主窗口后继续后台常驻，随时唤出。
- 支持在设置中开启“登录时启动”，默认关闭，使用 macOS 原生登录项管理。
- 点击菜单栏图标显示／隐藏主界面，右键进入设置或退出。
- 圆形悬浮球可拖动，自动吸附到屏幕边缘并记住位置。
- 默认只露出半个图标，鼠标悬停时以动画完整展开。
- 黑色吸附底座与屏幕边缘衔接，可通过设置或右键菜单隐藏悬浮球。

### 原生 macOS 外观与操作

- 毛玻璃窗口背景与圆角组件。
- macOS 26 及以上使用原生玻璃组件，较早系统使用兼容样式。
- 浅色、跟随系统、深色三段式外观切换。
- 界面支持简体中文和 English，可在设置中选择语言或跟随系统，切换即时生效；自定义名称和备注保持不变。
- 启动项和应用库均支持列表／图标布局。
- 图标大小、网格间距可调。
- 支持触控板双指左右滑动切换分类，可在设置中关闭。

### 本地数据与备份

- 分类、启动项和使用记录采用本地 JSON 存储。
- 自动保留上一份有效数据，支持导出备份、恢复上次备份及从 JSON 文件恢复。
- 恢复前另外保留原文件，方便撤回。
- 数据读取失败时保留原文件并停止覆盖保存。
- 扫描、编码和保存使用后台队列；正常退出时等待待处理保存完成。
- 不持续轮询应用目录，不包含账号登录、遥测或数据上传逻辑。

## 下载与安装

**系统要求：macOS 14 或更高版本。**

当前提供 Universal 通用版，包含 Apple Silicon（arm64）和 Intel（x86_64）架构。Intel 版本已完成构建，尚未进行实机验证。

1. 在本仓库的 **Releases** 页面下载最新的 `.dmg` 安装包。
2. 打开 DMG，将 **Nest Launcher.app** 拖到 **Applications（应用程序）**。
3. 从应用程序目录打开 Nest Launcher。

### 首次打开的安全提示

当前发布包使用临时签名，未经过 Apple Developer ID 签名和公证。通过浏览器下载后，macOS 可能阻止首次打开。

请先确认安装包来自本项目的可信发布页面，再按照系统提示到“系统设置 → 隐私与安全性”中允许打开。无需关闭系统安全保护。

## 快速上手

1. 首次打开时，右侧“全部应用”栏默认展开。
2. 在左侧新建分类，例如“开发”“办公”或“设计”。
3. 将右侧应用拖入对应分类，也可直接从 Finder 拖入。
4. 双击启动应用；用 `Option + Space` 快速显示／隐藏窗口。
5. 在设置中调整界面语言、登录时启动、快捷键、悬浮球、双指手势，或导出数据备份。

常用操作：

| 操作 | 方式 |
| --- | --- |
| 显示／隐藏主界面 | `Option + Space`，可自定义 |
| 打开设置 | `Command + ,` |
| 新建启动项 | `Command + N` |
| 新建分类 | `Command + Shift + D` |
| 彻底退出 | `Command + Q`，或右键菜单中的“退出” |

关闭主窗口不会退出应用。若希望开机登录后自动运行，请先将应用安装到应用程序目录，再在设置中开启“登录时启动 Nest Launcher”。该功能在登录 macOS 后启动应用，不会在登录前运行；如显示等待批准，请到“系统设置 → 通用 → 登录项”中允许。系统设置中的更改会在返回应用时同步。

单个启动项中的“快捷键备注”仅用于记录文字，不会注册该应用的启动快捷键；真正生效的全局显示／隐藏快捷键在设置中配置。

## 数据位置

默认数据文件：

```text
~/Library/Application Support/NestLauncher/data.json
```

应用名称为 **Nest Launcher**，内部模块与数据目录统一使用 `NestLauncher`。从使用其他数据目录的旧版升级时，请先在旧版设置中导出数据，再在新版恢复；两个版本的偏好设置独立保存。

- `data.json.backup`：上一份有效数据，后续保存会更新它。
- `data.json.before-restore-<标识>.json`：恢复前保留的原文件。

导出／恢复针对分类、启动项和使用记录，不包含语言、主题、快捷键、登录项和悬浮球位置等设置。长期备份建议使用设置中的“导出数据”，不要只依赖上一份自动备份。强制结束进程不保证尚未写盘的数据已保存。

## 从源码构建

项目采用 Swift、SwiftUI、AppKit 与 Swift Package Manager。构建需要 macOS 和完整的 Xcode 工具链；使用原生玻璃组件的源码需要包含对应 macOS SDK 的 Xcode 版本。

在仓库根目录执行：

```bash
# 当前机器架构的开发版本
bash ./make-app.sh debug
open "dist/Nest Launcher.app"

# Apple Silicon + Intel 通用发布版本
bash ./make-app.sh release universal

# 生成通用版 DMG
bash ./make-dmg.sh universal
```

应用产物位于 `dist/Nest Launcher.app`，安装包命名为 `Nest-Launcher-<版本>-universal.dmg`。也可指定 `native`、`arm64` 或 `x86_64` 构建单架构版本。脚本不会覆盖已有的同名 DMG，请先将旧安装包移到其他位置。
